
Q1: Why might we consider using Git?
Answer: Git tracks changes to files, preserves the previous versions and lets multiple people work on the project without overwriting each other's work. 

Q2: What field could data science be applied to? Give an example?
Answer: Data science could be used in healthcare. For example, hospitals would be able to analyze patient data to predict risk of disease and improve treatments. 

Q3: What is the difference between Merging and Rebasing?
Answer: Merging combines branches and preserving their separate histories, while rebasing moves commits onto another branch to create a more linear history.
